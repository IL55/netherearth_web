# Controls & Key Bindings

Default key bindings. Players can rebind keys from the in-game startup menu.

## Camera

| Key | Action |
|-----|--------|
| `a` | Pan camera target −z |
| `d` | Pan camera target +z |

## Ship movement

| Key | Action |
|-----|--------|
| `Arrow Keys` | Move ship horizontally (forward, backward, left, right) |
| `Space` | Ship ascend |

## Manual robot control (when active)

| Key | Action |
|-----|--------|
| `Arrow Keys` | Move / rotate the robot |
| `Space` | Fire equipped weapon |
| `x` | Detonate nuclear bomb (if equipped) |

## Debug / dev

| Key | Action |
|-----|--------|
| `t` | Cycle owner for all factories and warbases |
